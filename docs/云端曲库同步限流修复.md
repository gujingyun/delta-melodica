# 云端曲库同步限流修复（2026-09-20）

手机批量同步逐首请求私有曲库，原 Nginx 将其与登录、验证码共用每秒 1 次、突发 8 次的限流区。服务器错误日志确认曲库请求触发限流。Nginx 的非 JSON 错误响应导致旧手机端显示 JSONObject 转换错误。

## 线上修复

`server/fix_cloud_sync_rate_limit.py` 为 `/melodica/account-api/library/` 增加独立的每秒 12 次、突发排队 30 次限流区，不修改登录限速。转发保留 `/library/` 前缀，沿用账号接口的请求头、超时和并发限制。

服务器执行：

```sh
python3 server/fix_cloud_sync_rate_limit.py \
  --config /etc/nginx/default.d/delta-melodica.conf \
  --zones /etc/nginx/conf.d/90-delta-melodica-ddos-guard.conf --apply
```

不带 `--apply` 只检查。应用前备份并校验，应用后校验和重载，失败自动恢复。已在线应用，备份位于 `/var/backups/delta-cloud-sync-20260920-092105`。手工回滚时将 `0.before` 恢复到上述 config 路径，将 `1.before` 恢复到 zones 路径，然后运行 `nginx -t && nginx -s reload`。

以后重新部署完整 Nginx 路由配置后，也应运行本修复脚本，避免独立同步路由被覆盖。

## 手机端

`AccountResponse` 按 HTTP 状态处理限流、登录失效、网关故障，并将空正文、HTML 或非对象 JSON 转为中文提示，避免显示解析异常。此项需要后续发布新版 APK；线上限流修复已兼容现有手机版本。

- 线上连续 25 次未登录曲库请求：25 次均为 HTTP 401 JSON，没有 429 或非 JSON；未读取或修改真实曲库。
