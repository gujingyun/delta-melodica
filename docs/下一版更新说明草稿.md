# 三角洲口风琴 Windows 更新说明（待审阅）

拟定版本：v0.14。当前官网公开版本为 v0.13，核对时间为 2026-09-13。本说明汇总 v0.13 之后、当前「新建简谱版」已经包含的功能；版本号与发布时间尚未正式设置。

## 对外更新说明草稿

本次更新围绕找谱、写谱、改谱和曲库管理，新增简谱工作台、多来源搜索及账号云同步，并优化主界面。

### 1. 全新主界面

- 采用炭黑与浅绿配色，重新整理曲库、演奏参数、旋律预览和播放操作区。
- 音轨、速度、移调与演奏方式集中显示，曲库支持滚动浏览。
- 曲目增加 MIDI、简谱、内置和云端来源标记，便于区分。

### 2. 新建简谱与乐曲编辑

- 「输入简谱」更名为「新建简谱」，打开统一的简谱工作台。
- 新建及有可校验原谱的曲目支持左侧编辑谱文、右侧实时查看谱面，显示音符、八度点、时值、小节、反复和歌词。
- 支持符号快捷按钮、修改调号与速度、整曲移调、撤销和重做；点击谱面音符可定位对应文字。
- 支持编辑已导入 MIDI、旧版简谱、内置曲目和云端曲谱。没有原谱的曲目使用精确音符文本编辑。
- 新建曲目保存后自动加入并选中曲库；编辑已有曲目时另存修改版，保留原曲。
- 新建简谱默认提供 C 调、100 BPM 的示例谱文，可直接修改。

### 3. 谱面试听跟随

- 编辑器支持试听全曲或选中片段，按 F9 停止。
- 原谱试听时，谱文和谱面同步高亮当前音符，并随播放位置滚动；支持反复回跳、休止、延音及选段试听。
- 编辑窗口支持最大化和还原；长谱自动分页，试听时跟随翻页。
- 修改谱文或关闭编辑器会停止试听，未保存修改在关闭时提示确认。

### 4. 多来源搜简谱 / MIDI

- 支持简谱空间、官网曲库、BitMidi、MidiWorld、MidiShow 五个来源，打开搜索窗口时默认全部勾选。
- 按曲名或作者／歌手搜索，结果显示来源；可按需取消来源、加载更多或打开源网页。
- 支持来源允许的直接下载、导入和本机试听，同内容重复下载会复用本地曲目。
- 简谱空间支持繁简体匹配，导入后保留原谱，可继续编辑。
- MidiShow 遇到人机验证时显示明确提示，并提供源站搜索入口；需按源站要求完成下载后再导入。

### 5. 账号与云端曲库

- Windows 客户端新增邮箱注册、验证码验证、登录、找回密码和主动同步曲库。
- 支持将游客曲库合并到账号，在其他设备登录同一账号后下载可演奏曲谱。
- 游客仍可使用本地导入、新建简谱、试听、演奏及公开曲库下载。
- 优化登录、注册和找回密码表单，只显示当前操作需要的字段。
- 修复退出登录后原游客曲库被隐藏的问题，保留原有曲目与每曲参数。

### 6. 曲谱下载与解析修复

- 手动导入、官网曲库和聚合搜索支持可编辑曲谱 JSON，修复将 JSON 当成 MIDI 读取导致的「MThd not found」错误。
- 支持文字简谱的反复、一二房子、同音延音、连奏、分段速度、段落调号及歌词中的相对转调。
- 导入简谱默认使用「按谱面规则」，也可选择「跟随源站播放」进行对照。
- 修复《青花瓷》等带歌词转调标记的简谱导入失败问题。
- 保留原谱文字、调号、速度、休止与重复音；缺少调号或速度、不支持的符号、下载失败与来源验证均提供相应提示。

## 升级与使用说明

- 启动新版前，从系统托盘彻底退出旧版，避免热键冲突。原本地曲库与设置继续沿用，无需重新导入。
- 下载、导入和保存不会自动开始游戏演奏；需要进入游戏口风琴界面后按 F8。
- 云同步目前传输可演奏音符、时值与音轨编号；原谱文字、歌词、原始 MIDI、每曲速度／移调／片段和系统设置不做跨设备同步。本地删除也不会同步删除云端曲目。
- 客户端当前支持文字简谱、MIDI 和曲谱 JSON；图片／PDF 识谱及 MP3 自动扒谱未集成到此发行版。
