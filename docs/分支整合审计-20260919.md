# 分支整合审计 · 2026-09-19

## 结论与本轮范围

此前发布的安卓 0.6.3 未包含 `codex/android-feature-sync` 的三页布局、原谱编辑、试听及片段编排。该分支与正式发布线从不同历史继续开发，版本号增加并不代表包含全部功能。

本轮以 `master` 的 `0a966f0` 为基线，真正合并 `codex/android-feature-sync`（`045c418`），版本设为 0.7.0／11。保留正式版五首内置曲目、JSON 下载、错误脱敏、三秒半音提示、权限说明、签名及构建检查；整合当前工作区的检查更新、紧凑播放条、可展开悬浮曲库和 5000 首目录上限。官网部署不在本轮范围。

合并时补齐五首内置曲目的原谱编辑、官网下载目录标题与编辑元数据兼容、搜索结果普通链接标题回退，并修复服务同实例重连后的销毁状态。新增回归验证这些交叉路径。

## 工作区与发布保护

根工作区原有 7 个安卓改动文件已按 SHA-256 备份，整合时保留其功能；其它服务器、网站和迁移归档草稿不纳入提交。发布签名留在仓库外，不提交密钥、真实服务地址、账号数据或归档。

本轮产物与官网旧版本分开标识，后续发布必须从包含本次合并的主线构建，避免再次由旧发布分支直接提升版本号。
