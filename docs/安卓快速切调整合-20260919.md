# 安卓 0.7.1 快速切调整合

## 变更

基于 0.7.0 主线 d7a85e3，移植 codex/android-gap32 最终方案（3489686f）及所需切调衔接基础。保留三页界面、原谱编辑、紧凑悬浮条、进度定位、三秒半音文字提示和同实例服务重连修复。

设置 → 切调速度 → 快速（试用，目标约 32 毫秒）。默认稳定模式，用户选择持久保存。变更模式会重新准备曲目，不自动开始演奏。

音键最后一段与松键后的变音顺序合批；预先计算有限气口，优先利用休止，短音至少保留原时值四分之三。完成回调只更新仍有效的播放批次，下一次触摸前检查目标窗口。减少每段触摸完成时的重复界面刷新，仍保留周期刷新。

仅移植最终实现，不合并 10 毫秒探测入口或其失败参数，不回退官网与权限逻辑。分支提交 ancestry 不作已移植与否的唯一依据。

## 验证

专用 CodexMergeCheck 模拟器、自建测试键盘和临时数据，不访问游戏或生产账号服务。

- 单元测试 61 项：60 通过、1 项线上测试跳过。
- 稳定模式计时回归通过，跨音区／半音累计延迟 0～3 ms；二倍速密集短音不丢音。
- 快速计时：普通连续跨音区平均接收空隙 33.375 ms；半音 28.75 ms；混合音区半音 28 ms；二倍速密集短音不丢音。
- 连续压力：64 音半音平均 30.92 ms，累计延迟 120 ms；64 音密集双变音平均 38.59 ms，累计延迟 668 ms。共 128 音无错音、漏音、叠按或手势取消。
- 完整快速模式触摸回归 18 项通过：校准、提示、暂停续播、停止归零、定位、变音批次中断、短音、悬浮条、前台与旋转保护、同实例重连。
- 切调速度界面选择、持久保存、重开恢复及切回稳定模式通过；切换不自动演奏。
- 界面截图：[设置入口](../android/docs/settings-switch-v071.png)、[模式选择](../android/docs/switch-speed-v071.png)。
- 32 ms 是目标，不保证所有曲段恒定达标。密集双变音仍可能拖拍，实际手游需手机试奏。

## 发布与回退

版本 0.7.1 / 12，使用既有正式签名，可从同签名正式包覆盖升级。官网部署单独处理。

出现漏切或错音先在设置中切回稳定模式。需要回退代码时，从 0.7.0 提交构建更高版本号正式包，避免卸载丢失本地曲库。

代码、测试和验证文档可进入 Git；APK、设备日志、签名密钥与服务端草稿不提交。
