# 安卓 v0.6.0 上线准备

渠道：官网直接提供 APK 下载。当前状态：本地候选包，尚未发布。

## 已完成的开发准备

- 包名 `top.aiygzn.melodica`，版本 `0.6.0`／6，Android 8.0+，目标 API 34。
- 公开曲库兼容 MIDI 与 `format: score` 的 JSON 曲谱；下载先检查大小、SHA-256，再解析完整毫秒音符。
- 主界面、账号页均可打开离线「权限与数据说明」，说明游客、注册继承、主动同步及卸载行为。
- 独立正式签名，密钥和加密密码仅保存在仓库外；Release 构建检查签名和调试标记，自动输出 APK、校验值和构建来源。
- Debug 与 Release 单元测试各 28 项通过；Release Lint 0 错误、23 警告（平台建议、文字国际化等）。设备回归另行记录。
- 2026-09-14 公开 HTTPS 回读：官网目录有 5 首 MIDI、1 首 JSON 曲谱；账号服务 `/health` 返回 `{"status":"ok"}`。未发送验证码邮件、未访问个人账号。

## 升级与数据迁移

旧预览包由 Android Debug 证书签名。v0.6.0 起的正式包使用新的固定证书，同包名异签名不能直接覆盖安装。旧包中先同步曲谱，登录官网账号页确认曲目可下载；没有同步的曲谱需保留原始文件。再卸载预览包、安装正式包并重新校准。不同手机厂商可能显示不同的签名冲突文案。不要让用户以清除数据或卸载作为无条件的第一步。

## 正式切换前仍需完成

1. 用实际手机、实际手游验证首次授权、12 点校准、变音、长音、密集音符、暂停停止释放、切出和锁屏；记录机型、系统版本和结果。
2. 对正式签名资料制作独立加密备份并验证可恢复。当前密码文件使用本机 Windows 用户 DPAPI 保护，不是跨电脑备份。
3. 审阅候选包和网页后再安排正式发布。上线 APK 不代表授权公开安卓源码；本机 Git 保护钩子仍保留。
