## 线上曲谱下载修复（Windows 预览）

本地成品：`dist/三角洲口风琴_曲谱下载修复版.exe`。先从系统托盘退出旧程序，再启动此版；进入线上曲库，刷新目录后下载。旧版遇到曲谱 JSON 会报 `MThd not found`，需要使用包含本次修复的程序。[下载成功截图](docs/online-score-download.png)。

「导入曲谱 / MIDI」、官网曲库和聚合搜索均支持可编辑曲谱 JSON。下载保留原谱文字、调号、速度、休止和重复音，可直接试听、编辑与演奏。原有 MIDI 下载继续可用。

维护者可用 `python app.py --smoke --smoke-online "官网曲名" --data-dir work/online-smoke` 在隔离曲库内检查真实官网下载、载入与原谱编辑，并生成结果和截图。`--smoke-online` 仅在冒烟模式可用。官网目录以 `format: "score"` 标记曲谱，下载检查大小、SHA-256、音符及原谱一致性；此预览版尚未替换官网公开客户端安装包。

## 搜简谱、导入后演奏（Windows 预览）

曲谱下载修复版保留默认勾选全部搜索来源、简谱规则增强、可读原谱编辑、窗口最大化、试听位置跟随及源站验证提示，单文件运行。[试听跟随预览](docs/score-follow-window.png) · [最大化窗口](docs/score-follow-maximized.png)。旧导入文件可直接打开编辑；要更换原来的解析模式，需重新搜索并导入。

MidiShow 可能要求 Cloudflare 人机验证，后台搜索此时不能获取结果。窗口会明确显示「需要浏览器人机验证」并提供「去 MidiShow 搜索」，带上本次曲名打开浏览器；验证后按源站账号／积分规则下载，再点「导入已下载 MIDI」。程序不会自动完成验证，浏览器的验证状态也不会自动共享给后台搜索。此时不再提示「未找到匹配曲目」，其他来源已返回的曲目仍可导入。[验证提示截图](docs/midishow-verification.png)。

修复《青花瓷》因歌词内转调标记而无法导入的问题：按歌词音节和占位符定位 `(+1key)`／`(升2key)`／`(降1key)` 等相对转调，累计应用于对应音符及后续旋律。普通字母杂字会显示所在行并提示核对；升降号、重复等演奏符号仍严格检查。《青花瓷》已联网导入，并逐音符核对谱源的音高和节奏。

1. 点击左侧「搜简谱 / MIDI」，输入曲名或歌手，点击「聚合搜索」。默认勾选简谱空间、官网曲库、BitMidi、MidiWorld、MidiShow 全部五个来源，可取消不需要的来源；重新打开窗口时恢复全选。简谱空间支持繁简体曲名匹配。
2. 选择结果，简谱规则默认「按谱面规则」，点击「导入简谱」或「导入后试听」。展开反复并处理连线、段落调号，保存到当前账号／游客曲库，标记为 `[简谱]`，默认采用「原谱 · 分音」。需要对照网站播放器时，可选「跟随源站播放」。
3. 关闭搜索窗口，可通过「编辑选中乐曲」修正音符或节奏。准备好游戏后按 F8 演奏，F9 停止归零；导入不会自动向游戏发送按键。

支持高低八度、升降音、半拍与更短时值、附点、延音、休止及谱中标注的分段速度。独立的 C／Em7／G7 等和弦行只作伴奏标记，不会误读为旋律。未标速度的部分按 **120 BPM**、未标调号按 **1=C4** 导入，窗口持续显示默认值提示，可在编辑器调速或主界面移调。

新增谱面演奏规则（用于导入的文字简谱）：

| 记号 | 演奏效果 |
| --- | --- |
| `|:1 2:|3` | 反复段演奏两遍，再吹 3；支持嵌套和相接反复 `:|:` |
| `|:1 2[1 3:|[2 4` | 第一遍 1、2、3，第二遍 1、2、4；房子标记写 `[1`／`[2`，`|1` 仍是小节线后的音符 1 |
| `1~1`、`(1 1)` | 相邻同音高合并为长音，只触发一次；可跨小节及速度变化，不能跨休止 |
| `(1 2 2 3)` | 不同音高的连线按连奏处理；重复音仍重吹，衔接留最多 25 毫秒重新触发 |
| `/key(C4)1 /key(D4)1` | 调号从所在位置生效；绝对调号开始新段并清除前段歌词的相对转调 |
| `1:1/3 2:1/3 3:1/3` | 按精确拍数演奏三连音；分数或小数以四分音符为一拍，谱面在音符上方标明拍数 |
| `// 这一段是前奏` | 独立注释行不演奏，不把说明中的数字当成音符 |

反复回跳恢复段首调号、速度和歌词转调状态；一房子的变速、调号不带入第二遍。省略 `|:` 时，从曲首或上一个已完成反复段之后开始反复。最多嵌套 8 层，展开后仍限制 30000 个音符、30 分钟。导入结果会显示实际处理的反复、延音和连奏数量。

「跟随源站播放」遵循已核对的[简谱空间解析器](https://jianpu.space/javascripts/je.js)行为：忽略反复及圆弧／`~` 连线，最后一个 `/key` 作为全曲调号；`[1`／`[2` 中的数字仍被网站当成音符。因此它与「按谱面规则」的结果可能不同。两种模式分别保存，不会覆盖已有曲目。

在线简谱编辑器优先保留原谱文字和导入模式，支持下述「原谱＋谱面预览」。没有可校验原谱的 MIDI／云端曲目仍使用精确音符格式：反复展开为实际音符，同音延音合并成长时值，调号换算成音高；此格式的括号仅表示连奏，`(1 1)` 保留两次起音。云同步仍只传标准音符和时值，原谱文字与局部连奏附注保存在本地。

曲目范围取决于谱源收录，不能保证搜到所有歌曲。目前主程序只读取文字简谱；图片／PDF 可由本机图片识谱插件转录后导入。D.C.／D.S. 跳转、额外房子或指定反复次数、专用连音组和装饰音写法、跨反复边界的连线仍未支持；遇到未知符号或不完整结构会说明原因并停止导入。圆括号在此语法中只表示连线，不能用作 ABC 三连音语法。三连音可用 `1:1/3` 这样的精确拍数保留；倚音可在确定借时后写成对应音符和拍数。精确拍数仅用于「按谱面规则」，不能与同一音符的减时线、增时线或附点混写。源网页、原谱文字、规则模式和处理提示保存在本地曲谱中，保存后可离线播放。

已完成解析、界面、真实联网导入、本机合成试听及成品冒烟验证；游戏内效果仍需试奏。本版仅本地交付，桌面代码推送到 `codex/jianpu-search`，未更新官网公开下载包。

## 原谱编辑与谱面预览（Windows 预览）

参考[简谱空间编辑页](https://jianpu.space/songList/650f084690e1087b5a0c2c45/edit)的文字记谱和谱面预览方式，在本地提供可编辑的原谱。[编辑器截图](docs/source-score-editor.png)使用自编样例。

- 已导入的在线简谱直接显示原调号、BPM、八度点、减时符号、小节和歌词，不再把它们全部转换成 `+#4:0.555555556` 这样的文字。《青花瓷》保留 `/key(A3)`、108 BPM；旧版导入文件只要仍有与音符一致的原谱，就能自动恢复，无需重新搜索。
- 左侧修改谱文，右侧实时显示数字、八度点、减时线、附点、延音、小节、反复和歌词；点击谱面音符可选中对应文字，支持拖动分栏调整宽度。符号按钮修改选中音符或光标前的完整音符，支持撤销；「调号」「速度」修改首个标记，后续段落标记保留，也可直接编辑谱文。
- 原谱模式的整曲移调修改调号，保留音阶数字、时值和歌词；选段试听从完整曲谱时间轴裁出相应片段，保留此前调号、歌词转调和变速，并包含选中段落在反复中的各次演奏。选中同音延音的一部分会按选中时段裁切，选择不完整音符时会提示修正。
- 编辑窗口右上角可最大化／还原，也可双击标题栏。原谱试听时，右侧谱面和左侧文字用绿色标出当前位置，随播放器实际进度滚动；反复回跳、休止、延音和选段试听均跟随原谱。播放标记保留编辑选区，停止、结束或修改谱文后清除。
- 「另存到曲库」保存原谱写法、解析模式、来源网址和实际音符，重开仍为原谱编辑；不覆盖原曲、不提交源站。保存前校验实际音符；过期或不匹配的原谱信息不会覆盖现有音乐。
- 原谱模式的 `(1 1)`、`1~1` 等按导入时选择的规则解释；精确音符模式仍使用原来的 `+1`、`1:1/2`、`(1 2 3)` 写法。没有原谱的 MIDI 不猜测调号或改变量化时值。
- 图片识谱也可保存为原谱格式，保留调号和右侧谱面；三连音等特殊时值在音符上方显示精确拍数，点击可定位包含分数的完整音符。升音、八度和移调保留拍数，附点按钮将精确拍数乘以 1.5；半拍、四分之一拍及延长按钮改用普通时值。旧的纯文本识谱文件需重新转换并导入原谱版，不能只修改格式标签。
- 谱面超过 2000 个符号时分页显示，可用上一页／下一页浏览，试听自动翻到当前音符所在页；长歌词和极长延音做紧凑显示，完整文字仍可编辑、试听和保存。当前是文字编辑配合预览，尚未实现拖拽音符或印刷级制谱；云同步仍只同步标准音符。

## 聚合搜索预览（Windows，尚未发布到官网）

本地试用成品：`dist/三角洲口风琴_聚合搜索版.exe`。从系统托盘退出旧版后启动，点击「线上曲库 / 聚合搜索」，输入歌曲名或作者，点击「聚合搜索」。[窗口预览](docs/aggregate-search.png)。此版本同时保留已有乐曲编辑器。

按试用反馈已移除 MP3 自动扒谱试验，当前成品无需 `audio-engine` 文件夹；主窗口见[移除后的截图](docs/audio-feature-removed.png)。

- 可勾选官网曲库、[BitMidi](https://bitmidi.com/)、[MidiWorld](https://www.midiworld.com/search/)和 [MidiShow](https://www.midishow.com/)；结果逐站显示，带来源及下载条件。支持取消、新搜索替换旧搜索、加载更多和按资源链接去重，单站超时不影响其他结果。
- 官网、BitMidi、MidiWorld 的公开 MIDI 可「下载并转换」或「下载后试听」。下载先校验大小、MIDI 内容及八键转换，再原子加入当前账号／游客曲库。同内容的聚合下载复用本地文件；关闭搜索窗口会取消未完成操作。
- 转换沿用「自动旋律」与「钢琴适配 · 连奏」，保留 MIDI 的音轨、变速和完整原文件，仍可调速、移调、选轨、编辑或设置片段。下载不会自动向游戏发键；「下载后试听」只开启本机 MIDI 试听。游戏内准备好后按 F8 演奏，F9 停止归零。
- MidiShow 搜索结果可打开源网页，按照该站的[账号与积分规则](https://www.midishow.com/help/credit.ab)下载，再点击「导入已下载 MIDI」。程序不会登录第三方账号或处理积分下载。
- 英文网站建议输入英文名或作者名；中文歌可尝试别名。网站验证码、限流、网络故障或页面改版会显示来源错误，可稍后重新搜索或打开源网页。没有匹配结果和来源不可用会分别显示。
- 本期搜索与转换对象为 MIDI 乐谱，不包含 MP3／视频自动扒谱、付费音源下载或图片简谱识别。右上角「浏览官网精选」保留原官网曲库与分页入口。

## 乐曲编辑预览（尚未发布）

本地试用成品：`dist/三角洲口风琴_乐曲编辑预览版.exe`。从系统托盘退出旧版后启动，在曲库选中乐曲，点击「编辑选中乐曲」。窗口效果见[编辑器截图](docs/score-editor-window.png)，类型标记与入口见[曲库截图](docs/score-editor-library.png)。

- MIDI、手写简谱、内置曲目和云端曲谱均可编辑。曲库使用 `[MIDI]`、`[简谱]`、`[内置]`、`[云端]` 标记来源；编辑保存的本地修改版显示为简谱。
- MIDI／云端曲谱按当前音轨与演奏方式提取单旋律。编辑的是完整原速乐曲，不写入主界面的速度倍率、移调或片段裁切；钢琴适配会整理和弦及伴奏尾音，原始 MIDI 保留，可重新选轨提取。
- 支持修改音高、八度、升降音、拍数、休止；可插入、删除、复制和粘贴文本，撤销／重做，以及整曲 -24～+24 半音移调。`Ctrl+A` 全选，`Ctrl+Z` 撤销，`Ctrl+S` 另存。
- 旧简谱保留原 BPM 和文字；MIDI 转换默认以 120 BPM 为显示基准，原始变速体现在精确拍数里，不会把每个音强行量化成一拍。改变 BPM 会整体改变播放速度。`++1`／`--1` 表示升／降两个八度，游戏音域折回仍在播放时处理。
- 支持「试听全曲」「试听选中」与 F9 停止；选段试听需选中完整音符。试听沿用游戏的音域映射，编辑时或关闭窗口会停止试听。连奏与分音仍可选择。
- 「另存到曲库」始终新建修改版并选中，保留原曲，不会自动演奏。未保存关闭时提示放弃修改；保存失败保留编辑内容。
- 保存使用既有云端曲谱格式，音符时间精度为毫秒；本地额外保留编辑文字、BPM 和演奏方式，重新打开可继续编辑。云同步仅同步标准音符与时值，文字注释、BPM 显示基准和演奏方式仍为本地信息。

验证命令：分别运行 `python -m unittest -v test_score_editing`、`python -m unittest -v test_score_editor`；后者使用独立曲库和自建 Tk 窗口。具体结果见[验证记录](验证记录.md)。本轮为 Windows 编辑器预览，未更新官网公开下载包。

## 开始使用

1. 先从系统托盘退出正在运行的旧版本，再双击 `dist\三角洲口风琴_v0.14.exe`，无需安装 Python。启动时会自动请求管理员权限，请在 Windows 弹窗中点「是」。如果当前已经是管理员环境，Windows 可能不重复弹窗；取消确认则不启动。
2. 选择内置示例曲，或点击「搜简谱 / MIDI」搜索曲谱；也可通过「导入曲谱 / MIDI」导入本地 `.mid`／`.midi`／曲谱 `.json`，通过「新建简谱」写谱。下载和导入后的曲目会保留在本地曲库。
3. MIDI 默认使用「自动旋律」和「钢琴适配 · 连奏」。可手动换音轨，或切换「原谱 · 分音」。点击「本机试听」确认节奏和旋律；试听使用本机 MIDI 合成器的口琴音色，和游戏音色会有差别。
4. 进入游戏，切换到英文输入状态，取出口风琴并进入演奏状态，确认当前可以手动按键吹奏。
5. 在游戏内按 **F8**，等待默认 5 秒倒计时后开始。也可以在助手内点击「游戏演奏」，再切回游戏。
6. 演奏中按 **F8** 暂停，再按 **F8** 从暂停位置继续；**F9** 停止并回到曲首。切出目标窗口会释放按键并保留进度，回到游戏后可按 F8 继续。

程序启动时不会自动演奏。启动后会在后台检查官网版本，发现新版本时弹框提示；也可以点击主窗口右上角的「检查更新」手动检查。网络不可用不会影响正常使用。播放期间曲目、音轨、演奏方式、片段和键位设置锁定，速度与移调可以随时调整。

## v0.8：多片段演奏与每曲设置记忆

- **每首独立记忆**：速度倍率、音调（移调半音）、演奏音轨、演奏方式、演出片段分别保存到当前曲目。切换曲目、通过悬浮窗选曲或重启程序后恢复；主窗口、悬浮窗和游戏内调速／移调快捷键的修改都会保存。同名的不同曲库条目不会互相覆盖。
- **设置片段**：选中曲目，点击「演出片段」旁的「设置片段…」。输入原曲起点和终点（如 `01:20.500`～`01:45`，也可直接填秒数），点击「添加到列表」，最后点击「保存片段」。最多 100 个片段，支持更新、删除、上移、下移，也可重复同一段。
- **依次连续播放**：按列表从上到下播放，自动跳过未选部分；每段内部的休止保留。跨越片段起止点的长音只播放选中部分，片段之间释放旧音；试听和游戏演奏使用同一份片段列表。
- **时间不随速度漂移**：片段按 MIDI 原始速度表对应的原曲时间保存，修改倍率仍然选中同一段旋律。主窗口和悬浮窗进度显示拼接后、按当前速度计算的播放时间。可先拖动进度定位，再打开片段设置，用「使用当前位置」填入对应的原曲时间。
- **暂停、定位与重播**：F8 在所选片段内暂停／继续；进度条只能定位到编排后的演出内容。F9 停止归零，下一次从首个片段开头播放；修改片段、音轨或演奏方式也会归零。播放完最后一个片段后自动结束。
- **恢复全曲**：在片段设置中点击「清空 / 全曲」，再点击「保存片段」。只清除当前曲目的片段范围，其余参数保留；「取消」放弃本次片段编辑。时间越界、起点不早于终点、所选范围没有可演奏音符时会提示修正。

旧版曲库、键位和悬浮窗设置无需迁移。首次使用或没有保存配置的曲目为 1 倍速、不移调、全曲；MIDI 默认自动旋律与钢琴连奏，简谱默认原谱分音。

## v0.4：钢琴 MIDI 连奏适配

针对钢琴 MIDI 出现细碎低音、急促换音和断续的问题，新增「演奏方式」选择：

- **钢琴适配 · 连奏**：整理近同时按下的钢琴和弦，保留高声部；不在高音结束时补吹已经响过的伴奏尾音。连接不超过 120 毫秒且相对于前音较短的间隙，保留长休止。
- **完整时值**：连奏不再提前 15% 松键，衔接处只留最多 25 毫秒重新触发，重复音仍会分别吹奏。原谱分音仍使用设置中的按住比例。
- **自动旋律**：优先推荐名称含旋律／人声的音轨，否则在音符较充足的音轨中推荐较高声部。推荐只是一种判断规则；旋律选错时可以手动切换音轨。
- **原谱 · 分音**：保留旧版最高音整理与按住比例。如果需要完全对照旧版，同时选择「全部音轨 · 取最高音」。

首次选择 MIDI 时默认开启自动旋律与钢琴连奏；内置示例和简谱默认使用原谱分音。每首曲目的速度、移调、音轨和演奏方式会自动保存，切换曲目或重启程序后恢复；未配置的曲目使用 1 倍速、不移调。同名的不同曲库条目分别记忆，不会改写导入的 MIDI。

本机这份《蒲公英的约定》测试：默认推荐 Track 1 高声部，演奏音段从旧版混合双手的 615 段变为 433 音，短于 40 毫秒的片段从 108 段变为 0 段，连接 85 处短间隙。2:42 附近预览中的细碎伴奏低音已移除。此结果针对当前导入版本，其他编配的 MIDI 会有不同结果。

钢琴适配是单旋律改编，不等同于还原钢琴双手、踏板混响或复杂多声部；有意的和弦琶音、装饰音可能被简化，可用原谱分音对照试听。原曲已有的长休止仍会保留。新版输入逻辑已在本机验证，游戏内最终听感需要实际试奏确认。

## v0.3：游戏上方的半透明悬浮窗

进入目标游戏时自动显示一个半透明、置顶的小窗，显示曲目、进度、当前音键和状态；切到其他软件时自动隐藏。建议把游戏显示模式设为「无边框窗口」；独占全屏下，普通桌面悬浮窗可能无法盖在游戏上方。

- **F7**：打开悬浮窗操作面板，显示鼠标以便选曲；再次按 F7 返回游戏。
- **选曲 / 调速**：面板内直接选择已导入的曲目，切换曲库页码或调整速度。
- **播放并返回游戏**：先恢复鼠标穿透、切回游戏焦点，再启动倒计时，无需手动 Alt+Tab。
- **F8**：播放／暂停／继续。在操作面板里按 F8，也会返回游戏后播放。
- **F9**：紧急停止。
- **拖动标题栏**：移动位置；点击「不透明」切换约 65%、82%、96% 三档显示效果。
- **打开主窗口**：进行 MIDI 导入、音轨选择、移调及完整设置。
- **隐藏悬浮窗**：关闭显示；F7 可重新打开。

观看状态下鼠标会穿透悬浮窗，不会挡住游戏操作或误接收鼠标变音键。F7 打开操作面板时会暂停当前演奏并保留进度。点击「返回 F7」只返回游戏，不自动开始播放。

悬浮窗位置、透明度和显示开关保存在 `%LOCALAPPDATA%\DeltaMelodica\overlay.json`。曲库和原设置继续沿用。

软件使用普通 Windows 桌面置顶窗口实现悬浮显示，不注入游戏进程。启动权限使用 EXE 的 `requireAdministrator` 清单声明。

## v0.2 修复：按了播放但游戏不响应

本机排查确认：游戏进程以管理员权限运行，旧版助手以普通权限运行。新版会显示自身权限、检测目标游戏的权限，在确定权限不一致时停止发键并给出重启指引。

底部持续显示 F6／F7／F8／F9 注册状态。若显示热键不可用，请先退出旧版助手和其他助手实例，再启动新版。也可以使用界面的显示／隐藏、播放与停止按钮。

「查看诊断日志」可查看是否收到 F8、目标游戏是否匹配、权限状态、Windows 是否拒绝输入和最终停止原因。日志保存在 `%LOCALAPPDATA%\DeltaMelodica\diagnostic.log`，只写入本机。

专用测试参数 `--game-test` 会在启动后倒计时 10 秒，向匹配的前台游戏播放《小星星》开头七个音，只执行一次；之后恢复正常选曲演奏。普通双击启动不会自动演奏。

## 默认键位与需要校准的项目

| 音符 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 高音 1 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 按键 | Z | X | C | V | B | N | M | ,（英文逗号） |

已确认逗号键是第八个音键，对应高音 1。

鼠标左键暂按 **降低一个八度（-12 半音）**，右键暂按 **升高一个八度（+12 半音）**，中键暂按 **升半音（+1）**。这些鼠标键按住时变音，音符结束后释放。中音 1 默认按 C4（MIDI 60）换算；此绝对音高也需要游戏内核对。

可在「键位与设置」中修改八个音键、基准音高、左右键偏移、中键升／降半音、倒计时及按住比例。若游戏采用的是点击切换模式，而非按住变音模式，需要进一步适配；第一版只实现按住模式。

先播放「音阶校准 · 低中高与半音」，核对低／中／高音、逗号键及半音的实际效果。若漏音，可降低速度倍率后再试。

## MIDI 转换方式

- 音轨名称兼容 UTF-8 与常见 GBK／GB2312 中文编码；按每条名称识别，兼容同一文件内混用编码。只修正读取时的文字显示，不改写原 MIDI；更新后重新选择曲目即可刷新名称，无需重新导入。
- 支持 PPQ 时间格式的 MIDI 0／1 型，读取完整速度变化；不支持 Type 2 与 SMPTE 时间格式。
- 自动忽略第 10 通道打击乐。可选择单独音轨或所有旋律音轨。
- 原谱分音将重叠音符按每个时刻的最高音整理成单旋律；钢琴适配按上文方式处理和弦与伴奏尾音。多通道混在同一音轨的文件暂不能进一步按通道选择。
- 支持 0.25～2 倍速与 -24～+24 半音移调。超出音域的音符会按八度折回可演奏范围，并显示调整数量；试听播放的也是调整后的音符。
- 不还原踏板、弯音、力度变化、歌词或所有 MIDI 控制器。原谱分音默认按住音符时值的 85%；钢琴连奏连接短间隙并使用完整时值和短松键间隔。
- 单文件最多 10 MB、200000 个事件、30000 个旋律音符，最长 30 分钟。
- **MP3／WAV 不能直接作为乐谱导入。**

## 新建简谱

点击「新建简谱」，打开与原谱编辑相同的简谱工作台：左侧编辑谱文，右侧实时预览谱面，支持符号按钮、调号／速度、撤销／重做、移调、全曲／选段试听及窗口最大化。新曲默认名为「我的旋律」，提供 C 调、100 BPM 的示例谱文，演奏方式默认「原谱 · 分音」；新建内容不受当前选中曲目影响。

填写曲名和谱文后，点击右下角「保存到曲库」或按 Ctrl+S。保存成功会自动选中新曲目，保留可编辑谱文，再次点击「编辑选中乐曲」可继续修改。保存不会自动播放；试听时按 F9 停止，关闭尚未保存的修改会提示确认。要在游戏中演奏，先进入口风琴演奏画面，再按 F8。

本地成品为 `dist/三角洲口风琴_新建简谱版.exe`，从托盘退出旧版后启动；[新建工作台截图](docs/new-score-workbench.png)。

新建谱文使用原谱写法：`/key(C4)` 设置调号，`bpm100` 设置速度；`1'` 高八度、`1,` 低八度、`1_` 半拍、`1=` 四分之一拍、`1-` 两拍、`0` 休止、`|` 小节线，`L:` 开头的行填写歌词。

旧版保存的简谱仍保留原来的输入格式，用空格分隔音符：`1 2 3:2 +1 -5 #4 0`。

- `1`～`7`：中音；`+1`：高音 1；`-1`：低音 1。
- `#4`：升半音；`b3`：降半音；`0`：休止。
- `:2`：两拍；`:0.5` 或 `:1/2`：半拍；默认一拍。
- `|` 只用于分节阅读；一行中的 `//` 后可写注释。

## 窗口与停止机制

默认目标标题关键词是 `三角洲|Delta Force|DeltaForce`。倒计时结束后只接受标题匹配的前台窗口，随后锁定该窗口及进程 ID。检查目标时排除助手自己的进程。需要时可在设置中改成游戏窗口的实际标题关键词。

F6／F7／F8／F9 使用 Windows 全局热键；若被其他软件占用，底部会持续显示不可用状态，诊断日志记录错误码，需退出占用程序后重启助手。通过 Windows `SendInput` 模拟键鼠，仅查询目标进程权限标志，不读取或修改游戏内存，不安装驱动。

Windows 对不同权限级别的进程有输入限制。v0.2 调整权限后，用户已确认游戏内演奏及鼠标音阶测试没有问题；v0.3 沿用同一输入方式，新增悬浮窗已在本机测试窗口验证，实际游戏显示效果仍需按当前窗口模式确认。官方接口说明：[Microsoft SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)。

首次试奏请先切到英文输入状态。本机输入自检发现，中文输入法可能将字母音键接管为文字输入，造成漏音或无响应；助手不会自动修改游戏的输入法。

## 本地文件

项目已迁移到 `D:\projects\三角洲口风琴`，源码与 `.git` 位于目录根部，保留完整本地提交历史。

- `app.py`：软件入口；`build.ps1`：构建脚本。
- `dist\三角洲口风琴_v0.14.exe`：本次正式成品，包含简谱工作台、五源搜索和账号云同步；普通构建脚本输出 `dist\三角洲口风琴.exe`。
- `releases`：历史发行版本和压缩包，保留原版本名称。
- `work`：依赖、测试数据与构建中间文件；`work\migration-backup` 保留迁移前源码副本。

更名不改变 `DeltaMelodica` 数据目录，以便自动沿用旧版曲库、键位和悬浮窗设置。

曲库与设置保存在 `%LOCALAPPDATA%\DeltaMelodica`。导入会复制 MIDI，原文件不受影响。游客本地使用不上传曲目或设置；注册继承和主动云同步会上传可演奏曲谱副本到当前账号的私有曲库，不上传游戏窗口信息或系统设置。删除该数据文件夹可清空本机曲库与设置，不删除云端曲库。

每首曲目的演奏参数及原曲片段范围保存在数据目录的 `song-settings.json`；全局键位设置仍保存在 `settings.json`。参数调整后立即保存，片段在点击「保存片段」后保存；写入失败会在主窗口提示，原设置文件保留。

程序无需联网运行。附带《小星星》《欢乐颂》《两只老虎》与音阶校准示例；示例 MIDI 也放在发行包的「示例 MIDI」文件夹中。

## 从源码运行和打包

需要 Windows、Python 3.13（含 tkinter）。在源码目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

测试与构建：

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_music
.\.venv\Scripts\python.exe -m unittest -v test_transport test_lifecycle
.\.venv\Scripts\python.exe -m unittest -v test_song_settings
.\build.ps1
```

`build.ps1` 将结果放在源码目录的 `dist` 下。自动化测试使用模拟输入，不会在游戏里实际发键。界面冒烟测试：

```powershell
.\.venv\Scripts\python.exe app.py --smoke --data-dir .\build\smoke-data
```

MIDI 解析使用 [Mido](https://mido.readthedocs.io/en/stable/files/midi.html)，依赖许可证随发行包提供。

额外的悬浮窗集成测试为 `python -m unittest -v test_overlay`。它只创建并点击本地测试窗口；建议在管理员终端运行，避免当前前台游戏的权限限制测试窗口切换焦点。

暂停与定位测试为 `python -m unittest -v test_transport`，使用模拟输出验证 F8 续播、主窗口和悬浮窗拖动、F9 中断、播放中调速／移调以及快速操作时的事件顺序。

曲目记忆与片段编辑测试为 `python -m unittest -v test_song_settings`，使用独立数据目录验证切歌／重启恢复、同名 MIDI 隔离、配置读写异常、片段列表编辑与取消。

曲库删除测试也包含在 `test_song_settings` 中，验证确认取消、内置示例保护、曲库目录边界、文件删除以及对应参数记忆清理。

托盘与窗口生命周期测试为 `python -m unittest -v test_lifecycle`，会短暂创建本地窗口和托盘图标，使用模拟播放输出验证退出清理。也可运行 `python -m unittest -v test_music test_transport test_song_settings test_lifecycle test_overlay` 执行全部测试。悬浮窗测试会向自建窗口发送已注册的 F6 热键；运行前请确保 F6 未被其他程序占用。
